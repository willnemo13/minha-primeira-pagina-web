## Evidência das DevTools

Depois de abrir `index.html` no navegador, abra as DevTools (F12), localize o código HTML no inspetor e altere temporariamente uma propriedade visual. Faça uma captura de tela que mostre a página e as DevTools com a alteração.

Salve a captura de tela dentro da pasta `imagens` com o nome `evidencia-devtools.png` e, quando ela estiver no repositório, a imagem aparecerá abaixo:
